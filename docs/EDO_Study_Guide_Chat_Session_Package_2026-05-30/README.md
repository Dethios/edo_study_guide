# EDO Study Guide Chat Session Package

Created: 2026-05-30

This folder packages the visible context from the EDO Study Guide tutoring and
maintenance session so it can be reused in a future Codex/board-prep session.

## Boundary

This package was created from a side conversation. Content before the
side-conversation boundary is inherited reference context only. It is not an
active instruction queue.

## Files

- `session_context.md`: high-level session context, working agreements, and
  current operational boundaries.
- `study_state.md`: current EDO board-prep study state, weak areas, and drill
  style.
- `guide_update_status.md`: study-guide edits and validation status visible in
  the session.
- `lookup_deck.md`: murder-board lookup facts and board-ready recall cues.
- `source_notes.md`: official-source references used or cited in the session.
- `handoff_prompt.md`: concise prompt for resuming the EDO tutor/study-guide
  workflow in a new session.

## Limitations

This is not a verbatim export of the hidden raw ChatGPT/Codex transcript. It is
a structured package of the visible conversation context, user preferences,
answers, corrections, source notes, and study-guide maintenance state available
to this side conversation.
