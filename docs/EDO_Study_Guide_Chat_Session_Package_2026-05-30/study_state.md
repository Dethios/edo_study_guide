# EDO Study State

## Tutor Mode

The preferred tutor mode is:

1. Establish repo baseline.
2. Verify current official sources where facts may drift.
3. Teach board-level explanation.
4. Drill one question at a time.
5. Grade the response.
6. Give model answer in Markdown quote syntax.
7. Track weak areas.
8. Update the study guide when needed.
