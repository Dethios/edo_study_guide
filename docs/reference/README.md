# Reference Docs

Imported manuals, style assets, and one-off supporting material for the study
guide.

Use this directory for source-support material. When a referenced policy,
statute, regulation, or Navy instruction may have changed, verify the current
primary source before updating board-prep content.

Keep derived study-guide prose in `tex/chapters/` and bibliographic references
in `tex/*.bib`. Do not treat imported documents here as automatically current.
