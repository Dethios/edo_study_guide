\section{EVM Exercise}

\subsection{Summary}
\begin{description}
  \item[\textbf{Purpose.}] Apply earned value calculations to a two-period data set to diagnose cost and schedule status~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item[\textbf{Focus.}] Compute performance indicators, interpret trends, and project cost outcomes using the same \ac{bcws}/\ac{bcwp}/\ac{acwp} vocabulary used in current DoD \ac{evm} guidance~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
\end{description}

\subsection{Exercise Inputs}
\begin{itemize}
  \item Two-period summary data for planned value, earned value, and actual cost~\autocite{edo-3-6-3-evm-exercise-2025}.
  \item Program budget targets and any stated profit or funding assumptions~\autocite{edo-3-6-3-evm-exercise-2025}.
\end{itemize}

\subsection{Calculation Checklist}
\begin{itemize}
  \item \ac{sv} and \ac{spi}, period and cumulative~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item \ac{cv} and \ac{cpi}, period and cumulative~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item \ac{tcpi} to budget or to the selected \ac{eac} target~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item \ac{eac} forecast, \ac{etc}, and \ac{vac} or estimated overrun/underrun~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item Estimated contractor profit, government cost, and \ac{pom} request impact~\autocite{edo-3-6-3-evm-exercise-2025}.
\end{itemize}

\subsection{Interpretation Prompts}
\begin{description}
  \item[\textbf{Status.}] Explain the program's cost and schedule health using \ac{sv}/\ac{cv} and \ac{spi}/\ac{cpi} trends~\autocite{edo-3-6-3-evm-exercise-2025}.
  \item[\textbf{Drivers.}] Identify the likely sources of variance and whether corrective action is required~\autocite{edo-3-6-3-evm-exercise-2025}.
  \item[\textbf{Projection.}] Describe the likely end-state cost using \ac{eac} and resulting profit or funding impacts~\autocite{edo-3-6-3-evm-exercise-2025}.
\end{description}

\subsection{Quick Review}
\begin{itemize}
  \item Board math starts with \ac{bcws}, \ac{bcwp}, and \ac{acwp}; positive variances and indices above 1.0 indicate favorable cost or schedule performance~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-EVM-Definitions-2026}.
  \item \ac{tcpi} is the future cost efficiency required to finish within \ac{bac} or a selected \ac{eac}, so use cumulative values for the board answer unless the problem explicitly asks for a period metric~\autocite{DoD-IPM-EVM-Definitions-2026}.
  \item Translate the calculation into a PM decision: variance driver, corrective action, \ac{ipmdar}/\ac{cfsr} follow-up, and whether the cost projection affects the \ac{pom} request~\autocite{edo-3-6-3-evm-exercise-2025,DoD-IPM-Policy-Guidance-2026}.
\end{itemize}
