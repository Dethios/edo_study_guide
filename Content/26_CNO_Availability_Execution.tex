\section{CNO Availability Execution}
\minibib

\subsection{Project Teams and Responsibilities}
\begin{description}
\item[\textbf{Shipyard team.}] The Project Superintendent (overall cost/schedule/safety owner), Project Manager (budget, earned value, planning integration), Assistant Project Superintendents (zone leads), Engineering \& Planning (technical work documents, boundaries), and Business \& Planning (funding, schedule coordination) form the core team~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item[\textbf{RMC/private-yard team.}] The Port Engineer, Ship's Maintenance Manager (SMMO), Ship's Force Maintenance Officer, \ac{tycom} representative, Contracting Officer, and contractor Project Manager manage planning yard availabilities~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item[\textbf{Ship's Force.}] CO/XO/CHENG maintain safety, tag-out, and configuration control; Combat Systems and Supply Officers coordinate tests, SOVTs, and material receipt~\autocite{COMFLTFORCOMINST4790-3}.
\item[\textbf{Specialists.}] Integrated Test Engineers, Project Support Engineers, Quality Assurance Specialists, Alteration Coordinators, and Administrative Contract Specialists provide focused oversight on testing, configuration, QA, and change management~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\end{description}

\subsection{Execution Phases}
\begin{enumerate}
\item \textbf{Nesting / Arrival.} Establish temporary services, fire watches, habitability, industrial hygiene controls, and turnover from Ship's Force to the Maintenance Activity; complete mandatory briefings (JFMM Chapter 2, Tag-out Users Manual)~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{Rip-out \& Access.} Remove interferences, open systems, and conduct initial Work Authorization Form (\ac{waf}) reviews; late identification of hazardous material and access conflicts is a top schedule killer~\autocite{COMFLTFORCOMINST4790-3}.
\item \textbf{Open \& Inspect.} Execute inspections (tank, structural, piping) and document growth work; per NAVSEA Standard Item 009-01, inspections should be 100\% complete by A+20\% to preserve schedule margin~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{Repair \& Production.} Complete component tasks, manage new vs.\ growth work approvals, and track critical path milestones using Task Group Instructions (\ac{tgi})~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{Testing, Trials, Certification.} Execute compartment turnover, Light-Off Assessment (\ac{loa}), Shipboard Operational Verification Tests (\ac{sovt}), Combat System Ship Qualification Tests (\ac{cssqt}), Builder's/Acceptance Trials, and Sea Trials before Production Completion Date (\ac{pcd})~\autocite{COMFLTFORCOMINST4790-3}.
\end{enumerate}

\subsection{Governance, Quality, and Work Control}
\begin{itemize}
\item \textbf{\ac{nsa} / Lead Maintenance Activity.} Certifies that work is authorized, technically compliant, and properly tested before acceptance; reviews Objective Quality Evidence (\ac{oqe}) prior to signing completion certificates~\autocite{COMFLTFORCOMINST4790-3}.
\item \textbf{Work control.} \acp{waf}, \ac{tgi} sequencing, and boundary tags must remain synchronized; growth work requires screening panels (Ship's Force, \ac{tycom}, KO) to verify funding, schedule, and technical impacts~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{New vs.\ growth work.} New work is undiscovered scope added post-award; growth work expands existing items. Both demand TYCOM approval, funding source identification, and contract mods (or JSN adjustments for public yards)~\autocite{COMFLTFORCOMINST4790-3}.
\item \textbf{Testing governance.} Chief Test Conductors manage test agendas; engineering agents and Ship's Force witness tests, and discrepancies must be adjudicated before certification events (e.g., LOA, CSSQT)~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\end{itemize}

\subsection{Lessons Learned}
\begin{itemize}
\item \textbf{Momentum matters.} Availability performance often collapses after undocking; maintain daily production meetings, emphasize housekeeping/safety, and enforce material staging to avoid second-half slumps~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{Communication is a weapon system.} Cross-functional representatives (yard, Ship's Force, \ac{tycom}, QA, Supply) must keep each other informed about configuration, testing, and material risks; unresolved disconnects manifest as trial failures~\autocite{edo-4-2-2-cno-availability-execution-2025}.
\item \textbf{Document everything.} Capture change incorporation, OQE, and lessons in the Navy Data Environment (\ac{nde}) immediately—waiting until the end invites errors and delays closeout~\autocite{COMFLTFORCOMINST4790-3}.
\end{itemize}
